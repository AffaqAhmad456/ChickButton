CHICKBUTTON — SHOPIFY PHASE 2B
=============================

WHAT CHANGED
- The visible storefront catalog now loads from GET /api/shopify/products.
- Existing visual layout/design is preserved.
- Home product cards use Shopify products.
- Shop/search/filter/sort use Shopify products.
- Product detail pages use Shopify product images, price, sizes and availability.
- Add/update/remove cart now send Shopify variant IDs to the Phase 2A cart API.
- Collections drive category filtering.
- Variant Size/Age options drive the size filter.
- Shopify inventory drives availability.
- No new SQL migration is required for Phase 2B.

IMPORTANT
- Keep the Phase 2A SQL migration (07_shopify_cart_migration.sql) installed.
- Shopify credentials belong ONLY in ChickButton-Backend/.env.local.
- Do not expose SHOPIFY_CLIENT_SECRET to the Vite frontend.
- Checkout/order creation is still the next migration phase. Do not treat Shopify cart items as production-ready Shopify orders yet.
- The existing wishlist database still points at the legacy Supabase product table. Shopify wishlist persistence will be migrated with the remaining commerce persistence work.
